# TX2 从零部署

在 NVIDIA Jetson TX2 上从零编译一个 C++ + TensorRT 推理工程的完整流程。

## 包含什么

- 环境检查：一条命令看清系统、CUDA、TensorRT、OpenCV、编译器版本
- 模型准备：ONNX 导出的两个关键参数（opset、`dynamo=False`）
- 编译与建引擎：含「怎么判断是慢还是卡死」的监控方法
- 五个必看的坑：IP 会变、scp 的 `~` 与通配符、传成功了其实是空的、时间戳判断、磁盘满
- 报错对照表：11 条常见错误的成因与解决

## 适用环境

JetPack 4.6.x / L4T R32.x / TensorRT 8.2 / CUDA 10.2 的 TX2 设备。
其它 JetPack 版本大部分步骤相同，版本相关的差异在正文里单独标注了。

> 本文档基于实际部署过程整理，环境版本、模型结构、命令参数因项目而异，**具体操作请结合自己的实际情况调整，仅供参考**。
